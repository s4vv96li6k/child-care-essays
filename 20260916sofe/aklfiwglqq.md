# 【沧州二院】首次承担全国第四次中药资源普查沧州地区普查

> 更新时间：2026-09-16 (UTC+8)

**第四次全国中药资源普查**

**市二院将首次对沧州地区中药资源进行普查**

      2019年8月29日，河北省沧州中西医结合医院与河北中医学院签署正式协议，由河北省沧州中西医结合医院负责沧州市范围内的中药资源普查任务，先期开展黄骅市与孟村两个县市。

      中药资源是中医药事业和中药产业生存发展的重要物质基础，是重要的生态资源。中药资源普查是全面获取药用资源信息的重要手段。我国历史上已经进行了三次中药资源普查，全面掌握中药资源的分布和蕴藏情况，但随着中药产业迅速发展，民众对中药需求不断扩大，中药资源从种类、分布、量、质、应用均发生了巨大变化，相关政策、法规的制定缺乏基础数据，以及中药材供给不稳定等都影响着中医药服务民众健康，因此有必要开展第四次中药资源普查工作。河北省是全国唯一兼有高原、山地、丘陵、平原、湖泊和海滨的省份，地处暖温带与湿地的交接区，是我国中药资源比较丰富的省区之一，此次普查工作省政府高度重视，成立了以河北省政府特邀咨询孙士彬为组长的河北省中药资源普查试点工作领导小组，全面协调、督导普查工作的执行和完成情况。

      沧州市作为河北省中医药文化底蕴深厚的地区，也是大宗道地药材产地，之前从未开展过中药资源普查工作。我市过去以菟丝子、葶苈子、蛇床子、车前子等优质中药材驰名全国。由于从未进行过资源普查，中药材的分布以及资源量没有底数，对我市中药发展及将来中药产业化，缺乏可靠数据支撑。特别是近年来环境变化较大，对中药材产生了重大影响。在我院中药学部闫国强主任申请下，于2019年8月29日成功与河北中医学院签约2019中药资源普查项目(Z135080000022-2019-16)任务书，将首次对沧州地区中药资源进行普查。普查沧州地区野生药材及栽培药材种类、分布、蕴藏量、资源变化趋势等，采集保存中药材资源标本，了解中药材加工技术及供求关系状况，全面、宏观地掌握我市中药资源整体情况，为制定我市中药产业发展规划提供科技支撑，为道地药材的种植、加工、一体化布局提供技术支撑，为招商引资提供新的亮点，也为全国中药产业的可持续发展提供依据。

//

     项目签订后，项目组进行了认真的准备，同时聘请承德医学院，河北中医学院教授为顾问。于2019年12月14日进行了首次资源普查活动，本次活动主要是进行演练，发现问题及时改正。本次普查在黄骅市大郭庄进行,采集了芦根、白茅根等药材标本，采访了名老中医王宝明，了解黄骅市验方，地方习惯用品种，为今后工作打下了基础。

     同时项目组也欢迎有志于中药资源普查的同志和我们一道参加资源普查，提供有效信息。

     闫国强，河北省沧州中西医结合医院中药药学部主任，河北中医学院教授；中华中医药学会医院药学分会常务委员；中药质量工程学学会临床药学分会常务理事；河北省中医药学会医院药学分会主任委员；河北省名老中医师；河北省沧州市中药研究所所长；河北省沧州市中药质控中心主任。

多年来一直从事中药制剂和中药饮片鉴别研究，开发了20多种院内制剂，其中一种制剂转化为国药准字药品。在膏方制作方面有丰富的实践经验，特别是北派膏方的生产，有独到的技术。在中药制剂研究、中药饮片鉴别、经方药材考证有较深的造诣，有着丰富的中药药学管理经验。
